# Código de terceros

Las clases de excepción (`cx_*`), interfaces de mensajes (`if_message`, `if_t100_*`),
`cl_message_helper`, `cl_abap_char_utilities` y los elementos de datos de esta carpeta
provienen del proyecto **open-abap** (https://github.com/open-abap/open-abap),
publicado bajo licencia MIT:

> MIT License — Copyright (c) 2020 open-abap

Las clases `cl_salv_*`, `cx_salv_*` e `if_salv_c_*` son implementaciones propias y
simplificadas para este simulador (no contienen código de SAP).
